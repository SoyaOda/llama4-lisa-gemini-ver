## ❌ **残存する重要課題**

### 1. 語彙サイズ問題（Critical）
**問題の詳細**:
```
- 必要サイズ: 262504 (画像トークン262146-262401をサポート)
- 実際サイズ: 262208 (194トークン不足)
- 画像トークン範囲: 262146-262401 (256トークン)
- 影響: 画像トークンへのアクセス不可能
```

**根本原因**:
- 事前処理チェックポイント作成時の語彙サイズ設定が不完全
- HuggingFace `from_pretrained`が元の語彙サイズ(262208)を強制的に維持
- 分散環境での`resize_token_embeddings()`がDTensorエラーを引き起こす

### 2. 強制リサイズの失敗
**試行したアプローチ**:
1. **標準リサイズ**: `resize_token_embeddings(262504)`
2. **CPU手動リサイズ**: CPU上での手動埋め込み層拡張
3. **デバイス別リサイズ**: デバイス固有の安全な手動リサイズ

**すべて失敗理由**:
```
DTensorエラー: "got mixed torch.Tensor and DTensor, need to convert all torch.Tensor to DTensor"
```
